# Skyve Whitepaper

## Vision and mission

Most balances sit still. Skyve exists so that a deposit can earn from the trading that already happens on Solana, without the holder having to watch a chart. The mission is a vault that does a short list of things, shows every number it produces, and lets the depositor leave at any time.

## Roadmap

### Phase 1: Foundation
Publish the site, the live market board and the written vault rules. Announce the contract address and official channels.

### Phase 2: First pools
Open deposits into a first set of pools. Release the five-line breakdown for every position.

### Phase 3: Automation
Switch on the keeper that recentres ranges, with its permissions and costs visible on each position.

### Phase 4: Expansion
Add further pools and assets after the first set has run in public.
